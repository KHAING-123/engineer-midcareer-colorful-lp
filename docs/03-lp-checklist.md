# LP制作 Checklist

## 1. Input確認
- [ ] Customer Inputを読む
- [ ] LPの目的・ターゲット・CTAを確認する
- [ ] 必須情報と不足情報を整理する
- [ ] 使用するSectionを確認する
- [ ] 文章・リンク・画像が揃っているか確認する
- [ ] 画像内の文字と入力内容が一致しているか確認する（FV・メンバー・最終CTA）
- [ ] 画像の設定パスと実ファイルの拡張子が一致しているか確認する（.png / .svg / .jpg）
- [ ] images-optimized に同名のWebPがあるか確認する（ある場合は、元画像との差し替え漏れがないか確認する）
- [ ] 画像内の文章を、別紙の原稿と突き合わせる

## 2. デザイン確認
- [ ] Colorful LPのReferenceを確認する
- [ ] Sectionの順番を確認する
- [ ] 再利用するLayout・部品を決める
- [ ] PC・SP用画像を確認する

## 3. 実装
- [ ] 作業前のGit差分を確認する
- [ ] Inputを既存Contentの項目に対応させる
- [ ] 指定された文章・リンク・画像を反映する
- [ ] 必要な場合のみComponent・CSSを調整する
- [ ] 入力にない情報を勝手に追加しない
- [ ] 既存の作業を上書きしない
- [ ] lpContent.js以外に直接記載された文章・リンク・画像を確認する（aria-label・読み上げ用テキスト・装飾画像など）
- [ ] index.htmlのtitle・descriptionを案件に合わせて確認する
- [ ] index.htmlのHero preloadのパスが、実際の画像ファイルと一致しているか確認する

### 案件の要件に合わせて決める項目
- [ ] 応募・問い合わせの導線をリンクにするか、表示のみにするか決める（Header CTA・最終CTA）
- [ ] 公開時のrobots設定（noindex, nofollow）を決める
- [ ] 仮リンク（example.com）の置き換え方針を決める
- [ ] ナビに含めるSectionを決める（全Sectionへのリンクにするか）

## 4. 動作・表示確認
- [ ] Buildが成功する
- [ ] PC表示を確認する
- [ ] SP 390px・375px表示を確認する
- [ ] 文章のはみ出し・重なりがない
- [ ] 画像が表示される
- [ ] 画像のwidth・height属性と実寸のずれによる表示の乱れがない
- [ ] ナビゲーションとCTAリンクを確認する
- [ ] ナビのhrefと、対応するSectionのidが一致している
- [ ] ナビにないSection（SUPPORT・FLOW・最終CTA）の扱いを確認する
- [ ] 固定ヘッダーとアンカー位置が重なっていない（PC・SP）
- [ ] Animationとメニューの動作を確認する
- [ ] メニューのキーボード操作（Escape・フォーカス）を確認する
- [ ] Openingの動作と、動きを減らす設定（prefers-reduced-motion）時の表示を確認する
- [ ] 仮リンク・未確定情報を一覧にする

## 5. 結果報告
- [ ] 変更内容をまとめる
- [ ] コードで確認したこと、ブラウザ・実画像で確認したこと、未確認のことを分けて報告する
- [ ] 不足素材・修正が必要な点を報告する
- [ ] 案件の要件に合わせて決める項目（応募リンク・robots・仮リンク）の状態を報告する
- [ ] 作業時間を記録する
